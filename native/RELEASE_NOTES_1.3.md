# Silo Player 1.2.0

Нативная версия Silo Player на Rust (egui) без веб-движка. Windows 10/11, 64 бита. Два вида файлов: установщик `Silo-Player_1.2.0_x64-setup.exe` и один портативный `Silo-Player.exe` (ставить не нужно). Оба уже содержат yt-dlp.

## Что нового в 1.2.0
- **yt-dlp внутри.** Библиотека встроена в приложение и сама распаковывается при первом запуске в `%LOCALAPPDATA%\app.silo.player.native\bin`: режим «Библиотека yt-dlp» работает сразу, ничего искать и ставить не нужно. Свой путь к yt-dlp в Настройках по-прежнему можно указать.
- **Первый запуск без ключей.** Экран ввода ключей убран, ключи сервисов вводятся только в Настройках (для режима yt-dlp они не нужны).
- **Cookies браузера для yt-dlp** (Настройки → YouTube, по умолчанию выключено). Включайте, если YouTube отвечает «Подтвердите, что вы не бот»: yt-dlp тогда использует вход в YouTube выбранного браузера на этом компьютере.
- В Настройках → Звук у уровней апскейла подписан эквивалент по полосе (не настоящий битрейт потока).
- Репозиторий: веб-версия (Tauri и React) убрана, `main` содержит только нативное приложение.

## Что было в 1.1
Подготовка двух следующих треков, режим «Библиотека yt-dlp», караоке, апскейл «Слабый» и «Средний» (Apollo), своя шапка окна, трей, глобальные клавиши. Подробно: [CHANGELOG.md](../CHANGELOG.md).

## Важное: условия YouTube
Режим «Библиотека yt-dlp» получает звук и видео **не через официальный плеер YouTube**. Это нарушает условия использования YouTube, а правила YouTube API Services запрещают отделять звук от видео и сохранять содержимое. yt-dlp распространяется на условиях лицензии Unlicense и входит в состав сборок; пользователь сам отвечает за соблюдение условий сервисов. Режим «Чистый YouTube» (официальный плеер) остаётся в Настройках.

## Нейросеть Apollo
Уровень «Средний» требует скачивания нейросети Apollo кнопкой в Настройках → Звук (около 2,7 ГБ, на диске около 5 ГБ). В файлы она не входит.

## Контрольные суммы
См. `SHA256SUMS.txt` в релизе. Файлы пока не подписаны сертификатом, поэтому Windows SmartScreen при первом запуске может показать предупреждение («Подробнее» → «Выполнить в любом случае»).
