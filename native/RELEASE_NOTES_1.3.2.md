# Silo Player 1.3.2

Нативная версия Silo Player на Rust (egui) без веб-движка. Windows 10/11, 64 бита. Файл один: установщик.

## Что нового в 1.3.2
- **Из коробки.** yt-dlp поставляется установщиком и сам обновляется; если его нет, программа скачивает его с проверкой SHA-256, поиск ждёт и работает сразу. Запуск yt-dlp втрое быстрее (папка вместо одного exe): быстрее поиск и старт трека.
- **Без плашек ошибок.** Ошибки пишутся в тихий журнал diag.log, плашки включаются в Настройках.
- **Эквалайзер.** Плавные пресеты и ползунки без щелчков, предусиление против клиппинга, мягкий ограничитель, кривая АЧХ.
- **Внешний вид.** Скруглённые углы окна средствами Windows; Настройки не замирают при проверке yt-dlp.

- **Поиск.** Подсказки и результаты появляются прямо при наборе.
- **Первый запуск.** Язык, ручная настройка эквалайзера под наушники, жанры, исполнители; ключей и лишних экранов нет.
- **Скачивание.** YouTube-треки скачиваются через yt-dlp, в Настройках есть «Открыть папку».
- **Волна** разнообразнее по языкам и жанрам. Крупные обложки чётче.

## Что было в 1.3.1
- **Меньше ложных срабатываний антивирусов.** yt-dlp больше не лежит внутри exe: он отдельный официальный файл (установщик) или скачивается самой программой при первом запуске с проверкой контрольной суммы. Добавлены манифест и сведения о версии. Подпись сертификатом пока нет, поэтому SmartScreen и отдельные антивирусы могут предупреждать.

## Что было в 1.3.0
- **«Волна» умнее.** Быстрее реагирует на пропуски и лайки, чаще предлагает новое по вкусу, почти не повторяется: недавние (до 1000) и разные версии одного трека (клип, lyrics, Topic) не возвращаются.
- **Бот-проверка YouTube.** Если YouTube не отдаёт звук с вопросом «Подтвердите, что вы не бот», приложение один раз спрашивает разрешение использовать вход из вашего браузера (Firefox, Edge, Chrome, Brave) для yt-dlp. Решение можно изменить в Настройках → YouTube.
- **Установка Apollo.** Исправлен счётчик (показывал вдвое больше), на диске одна копия PyTorch, при отмене всё лишнее удаляется.

## Что было в 1.2.0
- **yt-dlp** (с 1.3.1 отдельным файлом или загрузкой при первом запуске, см. выше): режим «Библиотека yt-dlp» работает сразу, свой путь в Настройках по-прежнему можно указать.
- **Первый запуск без ключей.** Экран ввода ключей убран, ключи сервисов вводятся только в Настройках (для режима yt-dlp они не нужны).
- **Cookies браузера для yt-dlp** (Настройки → YouTube, по умолчанию выключено). Включайте, если YouTube отвечает «Подтвердите, что вы не бот»: yt-dlp тогда использует вход в YouTube выбранного браузера на этом компьютере.
- В Настройках → Звук у уровней апскейла подписан эквивалент по полосе (не настоящий битрейт потока).
- Репозиторий: веб-версия (Tauri и React) убрана, `main` содержит только нативное приложение.

## Что было в 1.1
Подготовка двух следующих треков, режим «Библиотека yt-dlp», караоке, апскейл «Слабый» и «Средний» (Apollo), своя шапка окна, трей, глобальные клавиши. Подробно: [CHANGELOG.md](../CHANGELOG.md).

## Важное: условия YouTube
Режим «Библиотека yt-dlp» получает звук и видео **не через официальный плеер YouTube**. Это нарушает условия использования YouTube, а правила YouTube API Services запрещают отделять звук от видео и сохранять содержимое. yt-dlp распространяется на условиях лицензии Unlicense и входит в состав сборок; пользователь сам отвечает за соблюдение условий сервисов. Режим «Чистый YouTube» (официальный плеер) остаётся в Настройках.

## Нейросеть Apollo
Уровень «Средний» требует скачивания нейросети Apollo кнопкой в Настройках → Звук (около 2,7 ГБ, на диске около 5 ГБ). В файлы она не входит.

## Контрольные суммы
См. `SHA256SUMS.txt` в релизе. Файлы пока не подписаны сертификатом, поэтому Windows SmartScreen при первом запуске может показать предупреждение («Подробнее» → «Выполнить в любом случае»).
