# Changelog

## 1.3.2 — 2026-11-14

### Changed
- Первый запуск и поиск: yt-dlp ставится установщиком (папкой, запуск 0,5 с вместо 1,8 с) или скачивается программой, пока он скачивается, поиск ждёт и затем идёт сам; обновляется раз в сутки.
- Ошибки больше не показываются плашками: всё пишется в тихий журнал diag.log, плашки включаются переключателем «Показывать сообщения об ошибках» (Настройки → Как играть YouTube).
- Бот-проверка YouTube: на 30 минут трек молча играет через официальный плеер, один раз предлагается разрешить вход из браузера.
- Эквалайзер: плавные переходы значений (без щелчков), автоматическое предусиление против клиппинга, мягкий ограничитель вместо жёсткого среза, Q 1,4, фильтры в двойной точности, на странице видна суммарная кривая АЧХ.
- Окно: скругление углов средствами Windows (без ступенек).
- Настройки → Как играть YouTube: проверка версии yt-dlp идёт в фоне (раньше окно замирало на секунду).
- Релизы содержат только установщик и контрольные суммы.
- Поиск работает при наборе: подсказки через 0,25 с и результаты через 0,55 с, без экономии запросов (yt-dlp).
- Убраны бот-проверка YouTube, cookies браузера, плашки «не указан ключ», ключи Jamendo и Google Custom Search, эквалайзер по трекам.
- Первый запуск: язык, эквалайзер под наушники вручную (по умолчанию звук ровный), жанры, исполнители. Экраны-подсказки убраны.
- Скачивание YouTube-треков через yt-dlp (меню трека), кнопка «Открыть папку» в Настройках.
- «Волна» разнообразнее по языкам и жанрам.
- Крупные обложки в окне плеера до 1280 пикселей (maxresdefault у YouTube), мипмапы против ступенек при уменьшении.
- «Качество» работает для YouTube: 48, 128 и до 256 кбит/с.

## 1.3.1 — 2026-11-14

### Changed
- yt-dlp больше не вшит внутрь exe (антивирусы принимали вложенный исполняемый файл за признак вредоноса): установщик кладёт официальный yt-dlp.exe отдельным файлом, а портативный Silo-Player.exe при первом запуске скачивает его с github.com/yt-dlp/yt-dlp/releases и сверяет SHA-256 с официальным списком.
- В exe добавлены манифест (запуск без прав администратора, Windows 10 и 11) и расширенные сведения о версии.

### Docs
- README объясняет возможные ложные срабатывания антивирусов; тексты обращений к производителям антивирусов лежат в `docs/antivirus.md`.

## 1.3.0 — 2026-11-14

### Added
- Если YouTube просит подтвердить, что вы не бот, приложение один раз спрашивает разрешение использовать вход в YouTube из найденного браузера (Firefox, Edge, Chrome, Brave) для yt-dlp. Cookies читаются только локально, не сохраняются и не показываются.

### Changed
- «Волна» (Эхо): мгновенные пропуски учитываются сильнее, старые прослушивания забываются быстрее, на каждый слот рассматривается больше незнакомых жанров.
- «Волна» почти не повторяется: исключаются до 1000 последних прослушанных треков, разные версии одного трека (клип, lyrics, Topic) считаются повтором, топ исполнителя берётся с разных позиций.

### Fixed
- Установка Apollo: счётчик показывал вдвое больше реального (кэш и копия складывались), теперь одна копия на диске (жёсткие ссылки), прогресс в долях от ожидаемого размера, при отмене и сбое временные файлы удаляются.

## 1.2.0 — 2026-11-14

### Added
- yt-dlp встроен в приложение и распаковывается при первом запуске; режим «Библиотека yt-dlp» работает сразу после установки.
- Настройка «Cookies браузера для yt-dlp» (по умолчанию выключена) для случаев, когда YouTube просит подтвердить, что вы не бот.
- Скрипт `tools/fetch-ytdlp.ps1`: скачивает официальный yt-dlp с проверкой контрольной суммы.
- Портативный `Silo-Player.exe` одним файлом.

### Changed
- Первый запуск без экрана ключей: ключи вводятся только в Настройках.
- Веб-версия (Tauri и React) убрана из репозитория; страница проекта, политика и условия обновлены.

## 1.1.0 — 2026-11-14

### Added
- Режим «Библиотека yt-dlp» (по умолчанию): поиск, «Эхо», подборки, страница артиста, звук и клип YouTube без ключа API; запасной путь через зеркала и официальный плеер.
- Подготовка двух следующих треков заранее (кэш на диске).
- Караоке: бегущий текст LRCLIB поверх клипа или обложки.
- Апскейл звука: «Слабый» (достройка срезанного верха в реальном времени), «Средний» (нейросеть Apollo, скачивается по кнопке в Настройках → Звук), «Сильный» в разработке; в настройках подписан эквивалент по полосе.
- Версия 1.1.0 в окне, в свойствах exe и в установщике; сторонние лицензии и заметки о версии в установщике.

### Changed
- Основным приложением стала нативная версия на Rust (egui), без веб-движка. Веб-версия (Tauri и React) убрана из репозитория.
- Убраны Deezer, счётчик поиска YouTube и уведомления о смене трека.
- Меньше нагрузки на процессор и видеокарту в фоне и во время игр.

### Fixed
- Экран первого запуска, перемотка при сбое сети, потеря позиции при неудачной перемотке.
