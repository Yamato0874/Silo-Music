# Silo Player

Музыкальный плеер для ПК на Tauri 2 (Rust) и React/TypeScript. Windows, Linux и macOS собираются из одного кода, мобильная версия запланирована. Интерфейс на русском и английском, 7 тем.

Проект открытый, лицензия [MIT](LICENSE). Сторонние лицензии: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

## Возможности
- **Единый поиск** по скачанному, Jamendo, YouTube и SoundCloud, у каждого трека метка источника.
- **Плеер внутри окна**: Jamendo и локальные файлы (gapless, кроссфейд, эквалайзер, выравнивание громкости), YouTube через IFrame Player API и SoundCloud через Widget API во встроенных плеерах. Панель с видео по умолчанию скрыта (звук играет), включается в настройках. Без yt-dlp, ytmusicapi, Invidious и обходов условий сервисов.
- **Эхо** — бесконечный поток под ваш вкус: адаптивная модель (Beta-распределения по жанрам и исполнителям, выборка Томпсона), учится на доле прослушанного и оценках, подгружает новые треки заранее. Кандидаты берутся из всех источников, для которых есть ключи. Жанры организованы деревом (семейство, жанр, поджанр; около 400 жанров плюс настроения, контексты, эпохи, языки).
- **Главная страница**: запуск Эхо, волны по любимым жанрам, недавнее, понравившееся, плейлисты.
- **Оценки**: лайк, дизлайк, бан (бан исключает только этот трек).
- **Строгий язык**: выбранный язык исключает треки других языков в поиске, Эхо и подборках (по письменности и тегам; смягчается в настройках).
- **Импорт плейлистов**: файлы M3U/M3U8, PLS, CSV, JSON, список «Исполнитель - Название», ссылки на публичные плейлисты YouTube, SoundCloud, Jamendo. Треки подбираются поиском, видно найденное и ненайденное.
- Подборки, плейлисты, очередь, shuffle/repeat, история, загрузки (только Jamendo, где автор разрешил).
- Своя шапка окна без системной рамки.

## Ключи API
Ключи вводятся на первом запуске или в Настройках и хранятся только на вашем компьютере, в локальной базе. Они отправляются только в соответствующий сервис.
- **Jamendo client_id**: <https://devportal.jamendo.com> (бесплатно).
- **YouTube Data API key**: Google Cloud Console, включить YouTube Data API v3 и создать ключ. Квота 10 000 единиц в сутки, поиск стоит 100, поэтому результаты кэшируются на 14 дней, а «Эхо» берёт треки из жанровых плейлистов (1 ед. вместо 100). Квота сбрасывается в 11:00 по Москве.
- **SoundCloud client_id и secret**: <https://soundcloud.com/you/apps> (доступ по заявке).

## Сборка и запуск
Нужны Node.js LTS, Rust (rustup), на Windows ещё Visual Studio Build Tools с компонентом C++ и WebView2. Подробнее: <https://v2.tauri.app/start/prerequisites/>.

```bash
npm install
npm run tauri icon app-icon.png   # один раз, генерирует иконки
npm run tauri dev                 # разработка
npm run tauri build                     # установщики: target/release/bundle/nsis/*.exe и msi/*.msi
```
Тесты ядра: `cargo test -p silo-core`.

## Данные пользователя
База (`silo.db`: вкусы, история, оценки, плейлисты, настройки, ключи) лежит в папке данных приложения (`%APPDATA%\app.silo.player` в Windows) вне папки установки и переживает обновление. Версия схемы хранится в `PRAGMA user_version`; перед миграцией и раз в сутки делается копия в `backups/` (остаются 10 свежих).

## Конфиденциальность
Нет телеметрии и аккаунтов. Запросы идут напрямую с вашего компьютера в Jamendo, YouTube, SoundCloud и MusicBrainz (подсказки исполнителей). Встроенные плееры YouTube и SoundCloud работают по правилам этих сервисов и могут собирать свои данные.

## Условия сервисов и атрибуция
- **YouTube**: используется официальный Data API и встроенный плеер, видео не скачивается и не извлекается. Действуют [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service) и политика конфиденциальности Google. Проект не связан с Google и YouTube.
- **SoundCloud**: поиск через официальный API, воспроизведение только во встроенном Widget. Действуют [условия SoundCloud API](https://developers.soundcloud.com/docs/api/terms-of-use). Проект не связан с SoundCloud.
- **Jamendo**: музыка опубликована авторами под лицензиями Creative Commons. При использовании сохраняйте авторство (исполнитель, название, ссылка на лицензию) и соблюдайте условия конкретной лицензии (например, NC запрещает коммерческое использование, ND запрещает производные). Скачивание в приложении доступно только для треков, где автор его разрешил. Проект не связан с Jamendo.
- **MusicBrainz**: данные об исполнителях доступны по CC0, запросы идут с идентифицирующим User-Agent.

Названия и товарные знаки принадлежат их владельцам.

## Структура
- `core/` — Rust без Tauri: SQLite (`db.rs`), источники (`jamendo.rs`, `youtube.rs`, `soundcloud.rs`), модель Эхо (`echo.rs`), таксономия (`taxonomy.rs`), подсказки исполнителей (`artists.rs`), языковой фильтр (`langfilter.rs`), тесты.
- `taxonomy/taxonomy.json` — данные жанров; источник `tools/taxonomy.src.txt`, сборка `python3 tools/build_taxonomy.py`.
- `src-tauri/` — команды Tauri, окно, права.
- `src/` — интерфейс (React).
- `demo/`, `screenshots/` — демо-страница и скриншоты.
