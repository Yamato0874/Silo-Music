# Silo Player

Музыкальный плеер для ПК на Tauri 2 (Rust) и React/TypeScript. Windows, Linux и macOS собираются из одного кода, мобильная версия запланирована. Интерфейс на русском и английском, 7 тем.

Проект открытый, лицензия [MIT](LICENSE). Сторонние лицензии: [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

## Возможности
- **Единый поиск** по скачанному, Jamendo, Deezer и SoundCloud, у каждого трека метка источника. Текст ищется и подсказывается при вводе через публичный Deezer API (без ключа). Видео YouTube для трека Deezer ищется только при нажатии play: один поиск на трек, выбор по длительности и совпадению исполнителя и названия (каверы, караоке и клипы отсеиваются), найденное хранится в базе, повторное воспроизведение квоту не тратит. Когда 100 поисков YouTube в сутки кончились, видео ищется через Piped или Invidious; не нашлось — играет 30-секундный фрагмент Deezer. Под строкой поиска счётчик «YouTube сегодня N/100».
- **Плеер внутри окна**: Jamendo и локальные файлы (gapless, кроссфейд, эквалайзер, выравнивание громкости), YouTube через IFrame Player API и SoundCloud через Widget API во встроенных плеерах. Панель с видео по умолчанию скрыта (звук играет), включается в настройках. Без yt-dlp и ytmusicapi; Piped и Invidious используются только для поиска id видео, играет всегда официальный встроенный плеер YouTube.
- **Эхо** — бесконечный поток под ваш вкус: адаптивная модель (Beta-распределения по жанрам и исполнителям, выборка Томпсона), учится на доле прослушанного и оценках, подгружает новые треки заранее. Кандидаты берутся из всех источников, для которых есть ключи. Жанры организованы деревом (семейство, жанр, поджанр; около 400 жанров плюс настроения, контексты, эпохи, языки).
- **Главная страница**: запуск Эхо, волны по любимым жанрам, недавнее, понравившееся, плейлисты.
- **Оценки**: лайк, дизлайк, бан (бан исключает только этот трек).
- **Строгий язык**: выбранный язык исключает треки других языков в поиске, Эхо и подборках (по письменности и тегам; смягчается в настройках).
- **Импорт плейлистов**: файлы M3U/M3U8, PLS, CSV, JSON, список «Исполнитель - Название», ссылки на публичные плейлисты YouTube, SoundCloud, Jamendo. Треки подбираются поиском, видно найденное и ненайденное.
- Подборки, плейлисты, очередь, shuffle/repeat, история, загрузки (только Jamendo, где автор разрешил).
- Своя шапка окна без системной рамки.

## Ключи API
Ключи вводятся на первом запуске или в Настройках и хранятся только на вашем компьютере, в локальной базе. Они отправляются только в соответствующий сервис.
- **Jamendo client_id**: <https://devportal.jamendo.com> (бесплатно).
- **YouTube Data API key**: Google Cloud Console, включить YouTube Data API v3 и создать ключ. Квота 10 000 единиц в сутки, поиск стоит 100, поэтому результаты кэшируются на 30 дней (максимум по правилам YouTube API), а «Эхо» берёт треки из жанровых плейлистов (1 ед. вместо 100). Квота сбрасывается в 11:00 по Москве.
- **SoundCloud client_id и secret**: <https://soundcloud.com/you/apps> (доступ по заявке).

## Сборка и запуск
Нужны Node.js LTS, Rust (rustup), на Windows ещё Visual Studio Build Tools с компонентом C++ и WebView2. Подробнее: <https://v2.tauri.app/start/prerequisites/>.

```bash
npm install
npm run tauri icon app-icon.png   # один раз, генерирует иконки
npm run tauri dev                 # разработка
npm run tauri build                     # установщики: target/release/bundle/nsis/*.exe и msi/*.msi
```
Тесты ядра: `cargo test -p silo-core`.

## Нативная версия 1.1 (Rust, без веб-движка)
Вторая сборка того же плеера: интерфейс на [egui](https://github.com/emilk/egui), собственный звуковой движок (symphonia и cpal: эквалайзер, кроссфейд, gapless, скорость без смены тона, визуализатор), общее ядро `core/`. Код в папке `native/`, ставится отдельно от обычной версии, со своей базой. Заметки о версии: [native/RELEASE_NOTES_1.1.md](native/RELEASE_NOTES_1.1.md), сторонние компоненты: [native/THIRD_PARTY_NATIVE.md](native/THIRD_PARTY_NATIVE.md).

Главное в ней:
- **режим «Библиотека yt-dlp»** (по умолчанию): поиск, «Эхо», подборки, звук и клип YouTube через yt-dlp без ключа API; запасной путь через официальный плеер;
- **подготовка двух следующих треков** заранее (кэш на диске), мгновенный старт и перемотка;
- **караоке**: бегущий текст LRCLIB поверх клипа или обложки;
- **апскейл звука**: «Слабый» достраивает срезанный сжатием верх в реальном времени, «Средний» это нейросеть Apollo (скачивается по кнопке в Настройках, около 2,7 ГБ);
- своя шапка окна, трей, глобальные клавиши, плашка Windows.

Сборка (Windows, нужны Rust и Visual Studio Build Tools; WebView2 нужен только для официальных плееров YouTube/SoundCloud):
```bash
RUSTFLAGS="-C target-feature=+crt-static" cargo build -p silo-native --release --target-dir target-native
cargo test -p silo-native           # 14 автотестов: кэш, разбор yt-dlp, достройка верха, конвертация звука
# установщик (NSIS, makensis из состава Tauri): положите yt-dlp.exe в native/installer/bin, чтобы включить его в установщик, если вы вправе его распространять
cd native/installer && makensis silo-native.nsi
```
Служебные переменные для самопроверок (в обычной работе не нужны): `SILO_DATA_DIR`, `SILO_LOCAL_DIR` (отдельные папки данных), `SILO_DEMO` (снимки экранов), `SILO_SELFTEST` (проверка воспроизведения с поддельным yt-dlp).

**Предупреждение о режиме yt-dlp.** Он получает звук и видео не через официальный плеер YouTube, что нарушает условия использования YouTube (а правила YouTube API Services запрещают отделять звук от видео). yt-dlp не входит в установщик: пользователь сам ставит его и сам отвечает за соблюдение условий сервисов. Режим «Чистый YouTube» с официальным плеером остаётся в Настройках.

## Данные пользователя
База (`silo.db`: вкусы, история, оценки, плейлисты, настройки, ключи) лежит в папке данных приложения (`%APPDATA%\app.silo.player` в Windows) вне папки установки и переживает обновление. Версия схемы хранится в `PRAGMA user_version`; перед миграцией и раз в сутки делается копия в `backups/` (остаются 10 свежих).

## Конфиденциальность
Нет телеметрии и аккаунтов. Запросы идут напрямую с вашего компьютера в Jamendo, Deezer, YouTube (и при исчерпанной квоте в Piped/Invidious), SoundCloud и MusicBrainz (подсказки исполнителей). Встроенные плееры YouTube и SoundCloud работают по правилам этих сервисов и могут собирать свои данные.

## Условия сервисов и атрибуция
- **YouTube**: используется официальный Data API и встроенный плеер, видео не скачивается и не извлекается. Это относится к обычной версии и к режиму «Чистый YouTube» нативной; режим «Библиотека yt-dlp» нативной версии работает иначе (см. предупреждение выше). Действуют [YouTube API Services Terms of Service](https://developers.google.com/youtube/terms/api-services-terms-of-service) и политика конфиденциальности Google. Проект не связан с Google и YouTube.
- **SoundCloud**: поиск через официальный API, воспроизведение только во встроенном Widget. Действуют [условия SoundCloud API](https://developers.soundcloud.com/docs/api/terms-of-use). Проект не связан с SoundCloud.
- **Jamendo**: музыка опубликована авторами под лицензиями Creative Commons. При использовании сохраняйте авторство (исполнитель, название, ссылка на лицензию) и соблюдайте условия конкретной лицензии (например, NC запрещает коммерческое использование, ND запрещает производные). Скачивание в приложении доступно только для треков, где автор его разрешил. Проект не связан с Jamendo.
- **MusicBrainz**: данные об исполнителях доступны по CC0, запросы идут с идентифицирующим User-Agent.

Названия и товарные знаки принадлежат их владельцам.

## Структура
- `core/` — Rust без Tauri: SQLite (`db.rs`), источники (`jamendo.rs`, `deezer.rs`, `youtube.rs`, `soundcloud.rs`), подбор видео YouTube для трека (`ytmatch.rs`), модель Эхо (`echo.rs`), таксономия (`taxonomy.rs`), подсказки исполнителей (`artists.rs`), языковой фильтр (`langfilter.rs`), тесты.
- `taxonomy/taxonomy.json` — данные жанров; источник `tools/taxonomy.src.txt`, сборка `python3 tools/build_taxonomy.py`.
- `src-tauri/` — команды Tauri, окно, права.
- `src/` — интерфейс (React).
- `demo/`, `screenshots/` — демо-страница и скриншоты.
